# C39 — Diverse child-facing play interactions

Implements: `PRD-ACT-*`, `PRD-SES-*`, `PRD-PROG-001/002`, `PRD-BR-006`. Dependencies: C38 presentation contract, C36 end review and C37 session editor.

Authorization: same direct request as C38. Scope: seven distinct child-facing play renderers using existing KidButton/Card/theme, SemanticIllustration and native Animated/PanResponder. Reuse content/media and observation infrastructure; no standalone game engine/provider.

Acceptance: pair matching has single-piece destinations, sorting accepts multiple pieces per basket, sequencing assembles ordered steps, sentence mode assembles phrase blocks, hunt opens hidden objects and invites a request, scenes advance authored dialogue, and turns visibly passes the ball between people. Pair/sort support drag-to-place plus accessible select-then-place controls. Examples include animal food/habitats, object purpose, greeting/call/invitation/ownership and real-person turns. No timers punish the child, no judgement scores/stickers/mastery unlocks, and no automatic observation is created. An authored answer model is shown only at tracked full-model support; ordinary placement feedback is neutral.

All selected games run in one prepared course. Parent review remains after the learning sequence, independently per lesson. Skip/pause/retry follows the existing session engine. Game placements/dialogue are transient within the current activity and restart when the activity is remounted; lesson order/completion/prompt evidence and parent reviews remain durable. Do not claim durable per-piece game restoration. Media is not auto-resumed on foreground; no API in game/review actions. Parent-guided transfer is an invitation, not a fabricated outcome.

Tests: pure reducer tests cover placement capacity/reference safety, sequence uniqueness/undo, reveal versus request, dialogue progression and turn-taking without result fields. Catalog/contract tests cover 13 situations and seven modes. `scripts/practice-play-web-smoke.cjs` exercises all situations plus end reviews with real local Nest/JWKS/PostgreSQL at 320/390/768 px; desktop gesture evidence is separate from native touch evidence. Browser results/screenshots live under `artifacts/practice-feature/play-*` after actual execution.

Migration/rollback: C38 owns the additive presentation field/catalog. Hide play entry points before disabling renderer support, preserve saved activity schema readers and observation/outbox. No database reset or production deploy. Native drag/scroll/screen-reader/reduce-motion, device lifecycle/low-storage and professional content review remain release gates; browser execution does not prove them.

Executed on 2026-11-04: frontend `pnpm check` passed 63 suites / 305 tests with typecheck/lint/media validation; backend `pnpm check:api` passed 11 suites / 45 tests with typecheck/lint/build. Real-browser play scenario passed all 13 situations at 320/390/768 px, including tap placement, sequencing/phrase construction, reveal/request, dialogue, turns, final per-lesson parent review and real API sync without activity-loop API calls or browser errors. The 768 px run additionally performed a real pointer drag. Evidence: `artifacts/practice-feature/play-results.json` and play screenshots. Parent editor includes an explicit quick-select button for the interactive-play group; existing selected plans are not silently replaced.
